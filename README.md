# SlideLite

A lightweight, fast, offline **PowerPoint (.pptx) viewer for Ubuntu**.

> Open → View → Present.

SlideLite is a viewer, not an editor. It does not modify presentations.

_Work in progress. See [ARCHITECTURE.md](ARCHITECTURE.md) for the design._

## Running from source

```bash
sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1
./bin/slidelite presentation.pptx
```
